\subsubsection*{template$<$typename Scalar$>$\newline
class igl::\+\+Winding\+Number\+Antipodal\+Scene$<$ Scalar $>$}
Precomputed scene for the Antipodal Method generalized winding number. 

The scene stores only the weighted open-\/boundary edges of the input triangle mesh and a fixed antipodal reference direction {\ttfamily \doxylink{classigl_1_1WindingNumberAntipodalScene_a6fc4db3facd085fa682f597d2937dc59}{x0}}. Closed (manifold) meshes have an empty boundary and the fractional term is exactly zero.

Querying the winding number additionally requires an {\ttfamily Intersector} that returns the signed ray-\/mesh crossing count along {\ttfamily (p, \doxylink{classigl_1_1WindingNumberAntipodalScene_a6fc4db3facd085fa682f597d2937dc59}{x0})} over the original mesh; the scene itself is intersector-\/agnostic. See {\ttfamily \doxylink{classigl_1_1embree_1_1EmbreeIntersector_a1a01eaccc24a70a8e0e790d5ec2ee328}{igl::\+embree::\+\+Embree\+Intersector::\+signed\+Intersections\+Ray}} for an optimized concrete implementation.\hypertarget{classigl_1_1WindingNumberAntipodalScene_autotoc_md43}{}\doxysubsubsubsection{\texorpdfstring{Intersector concept}{Intersector concept}}\label{classigl_1_1WindingNumberAntipodalScene_autotoc_md43}
A type {\ttfamily I} satisfies the concept when it exposes:\+
\begin{DoxyItemize}
\item {\ttfamily using Origin\+Type = ...;} (3D row vector type)
\item {\ttfamily using Direction\+Type = ...;} (3D row vector type)
\item {\ttfamily int signed\+Intersections\+Ray( Origin\+Type origin, Direction\+Type direction, /\+\texorpdfstring{$\ast$}{*} defaulted tnear, tfar, mask \texorpdfstring{$\ast$}{*}/\+) const;}
\end{DoxyItemize}

{\ttfamily \doxylink{classigl_1_1WindingNumberAntipodalScene_ac646eb0207e4bf96682fa7e4924ade23}{winding\+\_\+number}} casts query point/\+direction to the intersector\textquotesingle{}s types at the call site, so a {\ttfamily double}-\/precision scene against a float-\/only intersector works without an adaptor.

Extract the open boundary as oriented, weighted edge segments. 

Each undirected edge \{min, max\} accumulates +1 for every triangle that traverses it as min→max and -\/1 for every traversal max→min. Interior edges of an oriented manifold cancel to zero and are dropped. Surviving edges are emitted with positive weight; the segment direction is flipped when the net count is negative so the weight is always \texorpdfstring{$>$}{>} 0. Non-\/manifold (≥3 incident triangles per edge) is handled the same way. The surviving net count becomes the weight.
